# Mein Morgen (Morgen-Pilot)

Web-App für die Morgenroutine auf dem iPad: eine Aufgabe nach der anderen, Zeitscheibe, Abfahrtsanzeige, ein Edelstein pro pünktlichem Morgen.

- `index.html` – die komplette App (eine Datei, keine Abhängigkeiten außer Google Fonts)
- Daten (Häkchen, Edelsteine, Einstellungen) liegen nur im Browser des jeweiligen Geräts.

## Auf dem iPad installieren
Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
